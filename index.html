Performance Scoring Model

Built a model to score players' match performance relative to other competitors at the same level.

Filming Stick

Used computer aided design to prototype, test, and manufacture a fence-mounted phone holder to film tennis matches.

Lacrosse Expected Goals Model

Used Python computer vision to track player and ball data from game film, then applied machine learning classification to build an expected-goals model quantifying the probability a shot results in a goal (ROC-AUC 0.83).

Subaru Engine Swap
